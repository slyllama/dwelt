# Dwelt: Iron Solstice

Design, build and garden in *Dwelt: Iron Solstice*, a steampunk game set in an overgrown post-apocalyptic world, featuring diverse environments to cultivate, and robust construction features. Play as a robotic armature, seeking to heal and rejuvenate a planet abandoned by humanity in the aftermath of a cataclysmic war. Unlock building components by cultivating and gardening each land - using them to build and decorate your own settlement - and begin to heal and reconnect a fractured planet.
